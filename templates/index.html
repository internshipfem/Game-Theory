Trust Loop

A Prisoner's Dilemma Game

Welcome to Trust Loop! This is an interactive game about trust, betrayal, and strategy based on the classical Prisoner's Dilemma.

Over 10 rounds, you and your opponent will decide whether to Cooperate or Betray. Your combined choices determine your scores.

Payout Parameters

🤝 Both Cooperate +3 points each
⚔️ Both Betray +1 point each
😈 You Betray & They Cooperate +5 for you, +0 for them
🥺 You Cooperate & They Betray +0 for you, +5 for them
Rules & Point System
🤝 Both Cooperate: + pts
⚔️ Both Betray: + pt
⚖️ Betray vs Cooperate: + pts / + pts

📚 Coding Cheatsheet:
  • my_history: List of your moves (e.g., ['cooperate'])
  • opponent_history: List of opponent's moves
  • len(my_history): Rounds played so far
  • random.random(): Random float 0–1 (random module is pre-imported)
💡 Simple Examples:
  • return "cooperate" (Always cooperate)
  • return "betray" (Always betray)
  • return "betray" if "betray" in opponent_history else "cooperate" (Grudger)
