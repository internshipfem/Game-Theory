# Trust Loop

Trust Loop is a simple Prisoner's Dilemma game built with Flask, HTML, CSS, and JavaScript.

## Features

- Choose between different AI opponents
- Play 10 rounds
- Cooperate or betray
- Score system based on Prisoner's Dilemma
- Basic UI
- Simple JavaScript game logic

## Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
